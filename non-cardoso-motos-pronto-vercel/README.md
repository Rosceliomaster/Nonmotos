# NON Moto Peças, Mecânica & Preparações

Landing page estática pronta para deploy direto na Vercel, Netlify ou Cloudflare Pages.

**As imagens JÁ ESTÃO incluídas** em `assets/img/` com os nomes exatos usados no HTML:
`oficina-hero.jpg`, `banner-servicos.jpg`, `logo-non.jpg` (além de `og-preview.jpg` e `favicon.png`).

## Deploy na Vercel

1. Extraia o ZIP **na raiz do repositório** (não dentro de uma subpasta).
2. Apague as pastas antigas `non-cardoso-motos/` e `nonmotos-vercel-pronto/` do repo.
3. Deixe **Build Command** vazio e **Output Directory** em `.` (raiz).
4. **Diretório Raiz (Root Directory):** `./` (raiz).
5. Conecte seu domínio próprio em **Settings → Domains**.
